The Project

This project was commissioned by a client that runs live game-show events. The goal was to replace their existing PowerPoint-based Jeopardy workflow with a dedicated application designed specifically for running the game.

The result was a standalone Godot application with a dedicated audience display and host control panel, allowing the game to be operated independently from the presentation shown to the audience.

The Problem

Before this application, the client used PowerPoint to run the game. While the approach worked, customizing the presentation required manually modifying numerous text and shape elements.

This made preparing customized games cumbersome and limited how much the presentation could be tailored to different events.

The Solution

I developed a purpose-built game-show application using Godot and GDScript. The application separates the audience-facing presentation from the controls used by the host.

Audience Display Presents the game and its content in a dedicated interface designed for a live game-show environment.

Host Control Provides the host with a separate interface for controlling the progression and state of the game.

Seasonal Themes Includes Fall, Summer, and Base visual themes to allow the presentation to better match different events.

Standalone Application Runs as a portable application without requiring a traditional installation.

Application Structure

The application is divided into two primary interfaces: one for the audience and one for the host.

Audience Display The presentation shown to the audience during the event.

Host Control Panel The interface used by the host to operate the game.

Results

20+ Live Events

The client has used the application for more than 20 live events. Continued use of the application demonstrated that it met the needs of the client's live-event workflow.

The client subsequently commissioned a second-generation version of the application.

What's Next?

The success of the original application led to the commission of a second-generation version, now called Cognito! - Master the Inquiry.

Cognito is being rebuilt from the ground up rather than simply extending the original application. The new version introduces a more structured architecture and provides a foundation for additional capabilities.

  • Godot Resource-based game data
  • Dedicated question-set creation
  • Image and video support
  • Expanded customization controls
  • Persistent audio settings
  • Persistent theme and color settings
  • FFmpeg video conversion
