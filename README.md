# Assignment 1
For this assignment, we'll practice your client-side web development skills with the traditional starter project - creating a portfolio site from scratch! If you already have a portfolio page, use this as an opportunity to experiment with a different style, presentation, or focus for your portfolio.

Your site must contain (at minimum):

- Home page
- About page
- Skills and Projects page
    - Highlight and describe at least one project you're proud of
- Resume page
    - Not just a PDF of your resume, although you can include one in the link
- Contact page
    - This can be static for now, with a fake email address. Once we learn more about server-side development, you'll be able to connect to actually connect this to a functional emailing service
The site must be visually appealing (to the best of your abilities), and must utilize HTML, CSS, and Javascript created by you from scratch for this assignment. Follow best practices (for instance, using separate Javascript and CSS files for styling and functions shared on multiple pages).

You may use external CSS libraries for styling - however, your code must be clean and easily readable by me (don't copy + paste blocks of minified code).

You should create a GitHub repository for this project, and use GitHub Pages to host it. While some of you may have existing website hosting space, I want to see that you can work well with version control - you'll need it for the group project.

## Deliverables

- Zipped copy of your site files (HTML, CSS, Javascript, images, etc)
- A link to your publicly hosted portfolio site on GitHub pages
    - If I can't access it online, you will get a zero. Double-check that the link works on someone else's computer.
- A link to your publicly hosted GitHub repository, with commits showing your efforts to build the website
