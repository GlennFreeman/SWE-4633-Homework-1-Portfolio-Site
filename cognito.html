The Project

Cognito! - Master the Inquiry is the second-generation version of a custom game-show application originally commissioned for a live-event client.

The original application was successfully used for more than 20 live events. Rather than continuing to extend the original implementation, Cognito is being rebuilt from the ground up with a more structured architecture designed to support additional features and customization.

Why a V2?

The original application successfully met the client's needs, but its architecture was not designed around the additional functionality that was eventually requested.

The V2 provides an opportunity to rethink the underlying structure and build the application around the requirements that have emerged through real-world use.

The New Architecture

One of the major changes in Cognito is the way game data is represented. The original application used TSV-based data, while Cognito uses Godot Resources to represent structured game content.

This provides a more flexible foundation for the game's data and allows additional properties and functionality to be incorporated as the application develops.

Cognito also introduces a dedicated question-set creation workflow, allowing game content to be created separately from the main game application.

Current Features

Game Presentation Provides the primary interface used to present the game during a live event.

Host Control Maintains a separate control interface for operating the game while the audience views the presentation.

Structured Game Data Uses Godot Resource files to represent game content instead of the TSV-based approach used by the original application.

Game Set Creation Includes the foundation for a dedicated tool for creating and managing game sets.

Custom Presentation Builds on the original application's themed presentation with a more flexible approach to customization.

From V1 to Cognito

Cognito represents more than an incremental feature update. It is a complete architectural redesign based on the experience gained from developing and deploying the original application.

The original project established the core game-show experience and proved the concept in a live environment. Cognito provides the opportunity to address the limitations of that implementation while creating a foundation for future requirements.
